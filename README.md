## 一、一句话说明

我们把「判断股票」拆成两件事：

| 层 | 干什么 | 现在有什么 |
|---|---|---|
| **考场** | 把一个信号放进历史里跑，算它到底赚不赚 | ✅ 已建好，10 项自测全过 |
| **老师** | 提供买卖信号（规则 / 模型 / 你自己） | ⚠️ 只有 1 个笨样本，等你请 |

**顺序很重要：先有考场，再请老师。** 反过来就是"先信，再找证据"，那是炒股亏钱的标准姿势。

## 二·五、和 `limitup`（打板副驾）是什么关系

你机器上已经有两个东西，**不是重复，是分工**：

| | `E:\DSH-Work\limitup` | `E:\DSH-Work\stock`（这里） |
|---|---|---|
| 叫什么 | 打板副驾 | 考场 |
| 干什么 | **实战**：盘中全屏弹窗、盘后复盘、盘前新闻链 | **验证**：历史回测、作弊检测、成本核算 |

**不要合并这两个。** 一个是冲锋的，一个是算账的，混在一起两边都做不好。

## 四、考场凭什么可信：四条铁律

`engine.py` 里写死了四件事，任何"老师"都改不了：

### 铁律一 · 看不到未来
信号函数拿到的是 `ctx.bars`，它**物理上只能读到今天为止**。
谁敢往后翻一根 K 线，引擎当场抛 `LookaheadError` 炸掉。

> 这是回测里最致命的坑。市面上绝大多数"胜率 80%"的策略，
> 就是在这里偷看的：用今天收盘价买入，却用了今天收盘才知道的信息。

### 铁律二 · 买不到就是买不到
- 开盘涨停 → 买不进（记入 `rejected`）
- 开盘跌停 → 卖不出
- 停牌 → 跳过
- A 股 T+1 → 当天买不能当天卖

### 铁律三 · 成本一分不少
佣金 0.025%（最低 5 元）、印花税 0.05%（卖出）、滑点 0.1%。
**不做"零成本回测"**，那种结果没有参考价值。

### 铁律四 · 同样的输入，永远同样的输出
没有随机数、没有隐藏状态。跑两次结果必须一模一样。

### 自测跑哪 10 项

1. 未来函数被拦截
2. 越界访问不返回数据
3. T+1 强制（无当日回转）
4. 涨停买不进
5. 跌停卖不出
6. 停牌日不成交
7. 记账准确（零成本买入持有 = 基准涨幅）
8. 手续费分毫不差
9. **瞎买必亏**（24 组随机信号平均收益必须 < 0）
10. 可复现

第 9 项是灵魂：**如果瞎买在扣完成本后还能赚钱，说明引擎有漏洞。**

## 五、怎么请一个"老师"

在 `lab\signals\` 里新建一个 `.py`，写个函数就完事：

```python
from lab.backtest.engine import Context, Decision

def my_signal(ctx: Context) -> Decision:
    # ctx.bars 只能看到今天和以前
    # ctx.in_position / ctx.holding_days / ctx.cash 都能用
    ...
    return Decision("buy", "理由写这儿")   # 或 "sell" / "hold"
```

然后在 `run_smoke.py` 里把 `make_ma_cross(5, 20)` 换成 `my_signal`，跑一遍。

**你不需要改引擎，也不需要懂回测。** 引擎负责公平，你负责出想法。

## 六、怎么接自己的数据（爬虫）

`sources.py` 里留了插槽。你爬到的数据，只要能整理成下面这种格式，注册进去就能用：

```python
from lab.data.sources import register_source

def my_spider(code, start, end, adjust=""):
    # 你随便怎么爬
    return [{
        "date": "2026-11-06",
        "open": 11.62, "high": 11.85, "low": 11.57, "close": 11.81,
        "volume": 1640276, "amount": 1927308000,
        "prev_close": 11.64,
        "limit_up": 12.80, "limit_down": 10.48,
        "suspended": False,
        "source": "my_spider",        # ← 留痕，一眼看出数据是谁给的
    }, ...]

register_source("my_spider", my_spider)
```

然后 `get_daily(code, source="my_spider")` 就会走你的爬虫。

**数据里每一行都带 `source` 字段**，以后混用多源也不会搞不清来源。

## 七、数据从哪来：哪些白嫖，哪些值得花钱

你问过"愿意付费，但要花在刀刃上"。这是实话版地图：

### ✅ 完全免费，够用（日线级别）

| 数据 | 来源 | 状态 |
|---|---|---|
| 日线 OHLCV（前/后复权） | akshare → 东财 | ✅ 已接通，实测可用 |
| 涨跌幅、换手率、振幅 | 同上 | ✅ 自带 |
| 龙虎榜明细 | `ak.stock_lhb_detail_em` | ✅ 有 |
| 个股资金流 | `ak.stock_individual_fund_flow` | ✅ 有 |
| 涨停板 / 连板高度 | akshare 多个接口 | ✅ 有 |
| 财报三表 | akshare | ✅ 有 |
| 股票列表 / 行业分类 | akshare | ✅ 有 |

**结论：做 T+1/T+2 的日线级回测，一分钱不用花。**

### ⚠️ 免费拿不到、或拿了也不够

| 数据 | 免费情况 | 花钱大概多少 |
|---|---|---|
| **历史分钟线** | akshare 只有最近约 5 个交易日 | 积分制，门槛明显 |
| **逐笔 / Level-2** | 基本没有 | 券商通道，年费量级高 |
| **历史五档盘口** | 没有 | 同上 |
| 实时推送 | 轮询可得，有延迟 | 券商 Level-1 免费，Level-2 收费 |

### 💡 关于"爬虫收集数据"，我的建议

**历史分钟数据，爬是爬不到的**——网页只给你最近几天，翻页也翻不回去。

但有一件事你现在就能做，而且越早越值钱：

> **从今天起，每天收盘后跑一次抓取，把当天的分钟数据存下来。**

三个月后你就有 60 天的分钟库，半年后 120 天。
这东西**没有任何地方能买到"从今天开始往后"的历史**——它只能靠时间攒。

这也是为什么 `sources.py` 一开始就带缓存：**抓一次，永久留在本地。**

### 付费的刀刃在哪

按你的风格（T+1/T+2，最多持 3 天），优先级是：

1. **先别花钱**。用免费日线把信号跑到能过考场，这一步能淘汰 90% 的想法。
2. 真跑出东西了，再考虑为**分钟线**付费（因为你的决策点在盘中）。
3. 逐笔/Level-2 最后再说——那个对"打板"有用，但对"回测验证"性价比很低。

## 八、已知的边界（不吹牛）

- 数据源：akshare 走东财，**会遇到反爬**。挂了就重试，或者换源，不要以为是代码错。
- 复权：默认前复权（qfq）。做长周期回测时注意，前复权会随分红调整历史价格。
- 涨跌停：按代码前缀判板块（主板 10%、创业/科创 20%、北交所 30%），**ST 的 5% 需要股票名称才能判**，目前没接。
- 停牌：靠"成交量为 0"判断，粗略。
- 最后两个交易日不开新仓（否则会出现"当天买当天结算"，污染 T+1 统计）。
- **回测赚钱 ≠ 实盘赚钱**。滑点、冲击成本、情绪、手抖，考场都算不进去。
